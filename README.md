# Evoker Fix

A Guild Wars 2 Nexus addon that fixes the Evoker familiar (F5) skill behaviour by preventing the user from using another familiar skill while one is already casting and additionally provides an optional cooldown overlay for clarity.

## Features

- **Evoker Familiar Fix** — Corrects the F5 familiar skill behaviour so it can't be used before the previous attack has finished casting.
- **Cooldown Overlay** — Optional in-game overlay showing the cooldown of the last-used Evoker familiar skill / time left until you can use the next one.
  - Draggable and resizable when `Move UI` is enabled in the addon options.

## Requirements

- [Nexus](https://github.com/RaidcoreGG/Nexus)
- Guild Wars 2 (64-bit)

## Installation

1. Download `EvokerFix.dll`.
2. Place it in `<GW2>/addons/EvokerFix.dll`.
3. Launch the game and enable the addon in Nexus.
